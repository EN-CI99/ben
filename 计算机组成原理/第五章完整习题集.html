第一节 存储器概述

17 题
1.单选按存储介质分类，下列哪一类「不属于」计算机存储元件？
  • A. 半导体存储器
  • B. 磁表面存储器
  • C. 光存储器
  • D. 真空管存储器
答案：D
按存储介质分为半导体、磁表面（如磁盘/磁带）、光介质（光盘）三大类。真空管早已淘汰。
2.单选随机存取存储器（RAM）的核心特点是？
  • A. 只能读不能写
  • B. 按地址访问，每个单元访问时间与地址无关
  • C. 只能顺序访问
  • D. 信息断电后永久保留
答案：B
RAM（Random Access Memory）：每个地址译码时间相同，访问时间与地址无关；半导体存储器属于 RAM。
3.单选主存（内存条）主要由哪种存储器芯片组成？
  • A. SRAM
  • B. ROM
  • C. DRAM
  • D. 闪存
答案：C
主存由 DRAM 芯片组成（当前多为 SDRAM/DDR 系列）；cache 用 SRAM；ROM 用于固化；闪存用于外存。
4.单选关于「易失性存储器」描述正确的是？
  • A. 电源关闭时信息自动丢失，如 RAM、cache
  • B. 信息可一直保留，如 ROM、磁盘
  • C. 可多次擦写
  • D. 一定比非易失性存储器快
答案：A
易失性 vs 非易失性：易失性断电丢信息（RAM、cache），非易失性不需电源维持（ROM、磁盘、光盘、闪存）。
5.单选关于「时间局部性」与「空间局部性」描述正确的是？
  • A. 时间局部性指访问邻近单元
  • B. 空间局部性指短时间内再次访问同一单元
  • C. 两者是相同概念
  • D. 时间局部性：被访问单元在短期内很可能再次被访问；空间局部性：被访问单元的邻近单元在短期内很可能也被访问
答案：D
时间局部性=同一单元短期内被再次访问；空间局部性=邻近单元短期内也被访问。两者共同支撑 cache 的高效。
6.单选在存储层次结构中，「指令直接面向的存储器」是？
  • A. 主存储器
  • B. cache
  • C. 辅存
  • D. 寄存器
答案：A
CPU 给出的是主存地址（逻辑地址），主存是层次结构中的核心存储器。
7.单选目前大多数通用计算机采用的编址方式是？
  • A. 按字编址
  • B. 按字节编址
  • C. 按位编址
  • D. 按页编址
答案：B
现代通用计算机几乎都是按字节编址（编址单位=1 字节），如 36 位地址寻址范围 0~2^36-1。
8.填空主存由 ____ 芯片组成；cache 由 ____ 芯片组成。
答案：DRAM；SRAM
9.填空层次化存储系统中数据只能在 ____ 两层之间传送；读数据时总是从慢速存储器传送到快速存储器。
答案：相邻
10.填空主存地址线的位数决定了主存地址空间的最大可寻址范围，例如 36 位地址的最大寻址范围为 0～____。
答案：2³⁶ - 1
11.填空编址单位是指具有相同地址的那些位元构成的一个单位，可以是一个字节或一个 ____。
答案：字
12.名词解释随机存取存储器（RAM）
按地址访问存储单元，每个地址译码时间相同，每个单元访问时间是一个常数、与地址无关的存储器，半导体存储器属于 RAM。
13.名词解释易失性存储器
在电源关闭时信息自动丢失的存储器，如 RAM、cache 等；反之断电后仍能保留信息的为非易失性存储器（ROM、磁盘、光盘、闪存）。
14.名词解释程序访问的局部性
CPU 访问存储器的规律：①时间局部性——被访问单元在短期内很可能再次被访问；②空间局部性——被访问单元的邻近单元在短期内很可能也被访问。局部性是 cache 高速缓存能显著提升性能的基础。
15.名词解释高速缓存（Cache）
由快速 SRAM 组成、位于 CPU 与主存之间的小容量高速缓冲存储器，用来存放 CPU 当前经常使用到的指令和数据；利用程序访问局部性提高 CPU 访存速度。
16.综合题画出计算机存储层次结构图，并说明层次化设计在速度、容量、价格方面的好处。
答案：
自上而下（速度由快到慢、容量由小到大、价格由贵到便宜）：
寄存器 → L1 cache → L2 cache → L3 cache → 主存（DRAM）→ 固态/磁盘（SSD/HDD）→ 磁带/光盘
好处：通过层次化组合，整体上获得「接近最快层的访问速度 + 接近最慢层的存储容量 + 接近最便宜层的平均价格」的最优折中。
17.综合题为什么在 CPU 与主存之间设置 cache 能提高 CPU 执行速度？
答案：
① 速度匹配：SRAM 速度接近 CPU，主存 DRAM 慢，cache 作为缓冲减少 CPU 等待主存的时间；
② 局部性利用：程序访问具有时间局部性与空间局部性，被频繁访问的指令/数据块放在 cache 中，多数访存可命中 cache 而无需访问慢速主存；
③ 总体上大幅降低 CPU 的平均访存时间，从而提升程序执行速度。

第二节 主存与 CPU 的连接及读/写操作

12 题
18.单选DDR3 SDRAM 芯片内部缓冲采用几位预取？
  • A. 2 位
  • B. 4 位
  • C. 8 位
  • D. 16 位
答案：C
DDR=2 位预取，DDR2=4 位预取，DDR3=8 位预取。预取位数每翻倍，总线时钟频率相对内部也翻倍。
19.单选DDR2 SDRAM 内存条芯片内部预取位数与总线时钟频率关系是？
  • A. 4 位预取，总线时钟频率 = 芯片内部 × 1
  • B. 4 位预取，总线时钟频率 = 芯片内部 × 2
  • C. 4 位预取，总线时钟频率 = 芯片内部 × 4
  • D. 8 位预取，总线时钟频率 = 芯片内部 × 2
答案：B
DDR2=4 位预取，总线时钟频率=内部 ×2；DDR3=8 位预取，总线时钟频率=内部 ×4。
20.单选用若干「位数较少」的存储芯片构成给定存储字长的内存条时，需要进行？
  • A. 位扩展
  • B. 字扩展
  • C. 同时进行字位扩展
  • D. 不需要扩展
答案：A
位扩展=横向并联多片以加宽数据位；字扩展=纵向堆叠以加宽地址范围（增加字数）。
21.单选CPU 通过哪种「桥接器」与主存相连？
  • A. CPU 直接连主存
  • B. 磁盘控制器
  • C. DMA 控制器
  • D. I/O 桥接器（存储器总线桥接）
答案：D
CPU → 系统总线 → I/O 桥接器 → 存储器总线 → 主存。
22.单选「存数指令（Store）」的功能是？
  • A. 从主存读数据到寄存器
  • B. 将 CPU 寄存器的内容存储到主存单元中
  • C. 清空寄存器
  • D. 增加 PC 的值
答案：B
取数（Load）=主存→寄存器；存数（Store）=寄存器→主存。两者构成访存指令的两大类。
23.填空SDRAM 芯片读/写受外部系统时钟 ____ 控制，与 CPU 之间采用同步方式交换数据。
答案：CLK（前端总线时钟）
24.填空DDR SDRAM 利用芯片内部的 ____ 缓冲区提供的双字预取功能，并利用时钟信号的上升沿与下降沿实现一个时钟内传送两个存储字。
答案：预取（Prefetch）
25.填空CPU 与主存之间通常由 ____ 线、地址线和控制线三类总线组成。
答案：数据
26.填空访存指令主要有「取数指令（Load）」和「____ 指令（Store）」两类。
答案：存数
27.名词解释SDRAM
同步动态随机存取存储器（Synchronous DRAM），读/写受外部系统时钟 CLK 控制，与 CPU 同步交换数据；目前主存常用 DDR/DDR2/DDR3 SDRAM 内存条。
28.名词解释位扩展
用若干片位数较少的存储器芯片并联以扩展数据位宽，达到给定存储字长的方法；扩展后每存储单元的位数增加，但存储单元总数不变。
29.综合题用 8 片 16M×4 位的 SDRAM 芯片组成一个 16M×32 位的内存条，需要采用什么扩展方式？请说明步骤。
答案：
目标：16M×32 位；现有：16M×4 位 × 8。
方式：位扩展（横向并联加宽数据位）。
步骤：8 片 16M×4 位芯片分两组，每组 4 片并联组成 16M×16 位；再将两组串联（一组提供低 16 位，另一组提供高 16 位）形成 16M×32 位内存条；地址线、控制线并联接到所有芯片，片选由高位地址译码产生。

第三节 硬盘存储器

18 题
30.单选磁盘读/写操作的三个步骤依次是？
  • A. 旋转等待 → 寻道 → 读/写
  • B. 读/写 → 寻道 → 旋转等待
  • C. 寻道 → 旋转等待 → 读/写
  • D. 寻道 → 读/写 → 旋转等待
答案：C
标准三步：①寻道（磁头移动到目标柱面）→ ②旋转等待（盘片转到目标扇区）→ ③读/写（传送数据）。
31.单选磁盘「平均存取时间」的正确公式是？
  • A. 寻道时间 + 数据传输时间
  • B. 寻道时间 + 旋转等待时间 + 数据传输时间
  • C. 旋转等待时间 + 数据传输时间
  • D. 排队延迟 + 控制器时间 + 数据传输时间
答案：B
存取时间=寻道时间+旋转等待时间+数据传输时间；响应时间还会加上排队延迟+控制器时间。
32.单选磁盘实际数据容量的正确公式是？
  • A. 2 × 盘片数 × 磁道数/面 × 扇区数/磁道 × 512B/扇区
  • B. 盘片数 × 磁道数/面 × 扇区数/磁道 × 512B/扇区
  • C. 2 × 盘片数 × 磁道数/面 × 扇区数/磁道 × 4KB/扇区
  • D. 盘片数 × 柱面数 × 扇区数/磁道 × 512B/扇区
答案：A
两面 × 盘片 × 磁道/面 × 扇区/磁道 × 512B = 总容量。每个盘片有正反两个面（2），每扇区通常 512B。
33.单选磁盘与主存高速批量数据交换通常采用？
  • A. 程序查询方式
  • B. 中断方式
  • C. 通道方式
  • D. DMA 方式
答案：D
DMA（Direct Memory Access）=直接存储器存取，由专用 DMA 控制器在不经过 CPU 的情况下完成外设与主存间的批量数据交换。
34.单选关于闪存存储元中「浮空栅」带负电荷时表示？
  • A. 0
  • B. 1
  • C. 不确定
  • D. 已擦除
答案：A
控制栅加足够正电压 → 浮空栅储存大量电子（带负电荷）→ 状态 = 0；不加正电压 → 少带或不带电子 → 状态 = 1。
35.单选SSD 的三大限制中，下列哪一项「不在」？
  • A. 写页前必须先擦除整个区块
  • B. 擦除后区块内页必须顺序写入
  • C. 擦除/编程次数有限
  • D. 不可读
答案：D
SSD 三大限制：①写前必擦整块；②擦后顺序写；③擦写次数有限（磨损均衡算法缓解）。读没有限制。
36.单选SSD 中「磨损均衡（Wear Leveling）」算法的目的是？
  • A. 提高读写速度
  • B. 增加存储容量
  • C. 将擦除操作平均分布在所有区块上以延长寿命
  • D. 降低功耗
答案：C
Wear Leveling：把擦除均匀分布到所有块上，避免某些块过早磨损失效，延长 SSD 寿命。
37.填空磁盘地址由 ____ 号、磁头号、扇区号三部分组成。
答案：柱面
38.填空磁盘每个盘片两个面上各有一个磁头，因此磁头号就是 ____ 号。
答案：盘面
39.填空磁盘完成磁头定位和旋转等待后的数据传输率称为 ____ 传输速率或持续传输速率。
答案：内部
40.填空SSD 中数据按 ____ 为单位进行读/写，擦除按区块为单位进行。
答案：页（Page）
41.填空闪存有 3 种基本操作：编程（充电）、擦除（放电）、____。
答案：读取
42.填空闪存全称 ____ 存储器，是一种非易失性读/写存储器。
答案：闪速（Flash）
43.名词解释DMA（直接存储器存取）
由专门 DMA 控制器在外设与主存之间直接进行批量数据交换的方式，数据不经过 CPU；常用于磁盘等高速外设的成批数据传送，提高 I/O 效率。
44.名词解释固态硬盘（SSD）
使用 NAND 闪存组成的外存设备，用闪存颗粒代替磁盘作为存储介质，按页读/写、按区块擦除；相比机械硬盘具有更快的随机访问速度，但有三大限制：写前必擦、擦后顺序写、擦写次数有限。
45.名词解释闪存（Flash Memory）
闪速存储器，一种非易失性读/写存储器，兼有 RAM 和 ROM 的优点，功耗低、集成度高、无需后备电源；每个存储元为单个带浮空栅的 MOS 管，有编程、擦除、读取三种基本操作。
46.综合题某磁盘驱动器有 4 个盘片（8 面），每面 5000 磁道，每磁道 1000 扇区，每扇区 512B，求总容量；若平均寻道时间 8ms、平均旋转等待 4ms、数据传输时间 0.5ms，求平均存取时间。
答案：
容量 = 2 × 4 × 5000 × 1000 × 512 B = 8 × 5 × 10³ × 10³ × 512 = 20 × 10⁹ × 512 ≈ 10.24 × 10¹² B ≈ 9.31 TiB（或 ≈ 10.24 TB 商用计法）。
平均存取时间 = 8 + 4 + 0.5 = 12.5 ms。
47.综合题简述 SSD 三个限制及其对操作系统/闪存翻译层提出的要求。
答案：
①写页前必须先擦除所在整个区块 → 写放大；需要 FTL（闪存翻译层）做异地写入。
②擦除后区块内页必须顺序写入 → 不能随机写；FTL 需维护逻辑→物理映射表。
③擦除/编程次数有限 → 块磨损失效；FTL 需实现 Wear Leveling（磨损均衡），把擦除均匀分布到所有块上延长寿命；同时用坏块管理。

第四节 高速缓冲存储器（Cache）

28 题
48.单选Cache 行中的「有效位（Valid Bit）」为 0 表示？
  • A. cache 行被修改过
  • B. cache 行中的主存块信息无效（空或被冲刷）
  • C. 命中
  • D. 写入主存
答案：B
有效位=0：cache 行空/被冲刷；=1：cache 行中已装入有效的主存块信息。
49.单选Cache-主存层次的「平均访问时间」公式是？
  • A. Ta = Tc + (1-p) × Tm
  • B. Ta = p × Tc + (1-p) × Tm
  • C. Ta = p × Tm + (1-p) × Tc
  • D. Ta = Tc + Tm
答案：A
命中 p 直接 Tc；缺失 (1-p) 需先 Tc 再 Tm 再合并；故 Ta = Tc + (1-p)·Tm。
50.单选「直接映射」中主存块号与 cache 行号的关系是？
  • A. cache 行号 = 主存块号 ÷ cache 行数
  • B. cache 行号 = 主存块号 + cache 行数
  • C. cache 行号 = 主存块号 mod cache 行数
  • D. cache 行号 = 主存块号 × cache 行数
答案：C
直接映射（模映射）：主存每一块固定映射到唯一一个 cache 行，行号 = 块号 mod 行数。
51.单选「全相联映射」的主要优点是？
  • A. 映射电路简单
  • B. 块冲突概率低（只要有空闲行就不会冲突）
  • C. 查找速度快
  • D. 主存地址无需标记字段
答案：B
全相联：主存块可装入任意 cache 行，块冲突概率最低；缺点是查找电路复杂、需比较所有行的标记。
52.单选组相联映射中「组间模映射、组内全映射」对应的组号公式是？
  • A. cache 组号 = 主存块号 × cache 组数
  • B. cache 组号 = 主存块号 ÷ cache 组数
  • C. cache 组号 = 主存块号 mod cache 每组行数
  • D. cache 组号 = 主存块号 mod cache 组数
答案：D
组号 = 主存块号 mod 组数（组间用模映射确定唯一组，组内可选任意行）。
53.单选下列替换算法中，能「较好反映程序访问局部性」的是？
  • A. LRU（最近最少用）
  • B. FIFO（先进先出）
  • C. 随机替换
  • D. 都不行
答案：A
LRU 选择近期最少使用的块替换，较好反映时间局部性；FIFO 简单但与局部性不一致；随机实现简单但效果稍差。
54.单选「回写法（Write Back）」的核心思想是？
  • A. 每次写都同时更新 cache 与主存
  • B. 只写主存不写 cache
  • C. 写命中只更新 cache，仅当该行被替换时才一次性写回主存
  • D. 写不命中时不做任何处理
答案：C
回写 = 命中只改 cache，块被替换时根据「脏位」决定是否写回主存；减少主存写入次数。
55.单选回写法中 cache 行的「修改位（脏位）」为 1 表示？
  • A. 该行是空的
  • B. 该行主存块被修改过，替换时需写回主存
  • C. 该行只读
  • D. CPU 正在访问该行
答案：B
脏位=1 说明与主存不一致，替换时需写回主存；=0 则可直接丢弃。
56.单选「全写法 + 写分配法」处理写不命中时？
  • A. 先更新主存，再把更新后的块装入 cache
  • B. 只更新主存，不装入 cache
  • C. 只更新 cache，不更新主存
  • D. 抛出异常
答案：A
全写 + 写分配 = 写不命中时，先在主存更新对应单元，再分配一个 cache 行装入更新后的主存块；充分利用空间局部性。
57.单选现代 CPU 中 L1 cache 通常采用？
  • A. 联合 cache（指令+数据合一）
  • B. 容量最大
  • C. 命中率最高
  • D. 分离 cache（数据 cache 与指令 cache 分开）
答案：D
L1 多为分离 cache（指令/数据分开），避免取指与取数的资源冲突；L2/L3 为联合 cache。
58.填空CPU 访问 cache 的顺序通常为 L1、L2 和 ____ cache。
答案：L3
59.填空系统启动或复位时，每个 cache 行都为空，信息无效；每行需要一个 ____ 位。
答案：有效（Valid）
60.填空将有效位清 0 来淘汰某 cache 行中的主存块称为 ____。
答案：冲刷（Flush）
61.填空直接映射中 cache 行号 = 主存块号 ____ cache 行数。
答案：mod
62.填空全相联 cache 中，主存地址中只需「标记」和「____ 地址」两个字段。
答案：块内
63.填空组相联 cache 将所有行分成 2^q 个大小相等的组，每组有 2^s 行；其中 q 决定组索引位数，s 决定组内行索引位数，s+q 加上标记位覆盖主存 ____ 号。
答案：块
64.填空FIFO 算法总是选择 ____ 装入 cache 的主存块被替换掉。
答案：最早
65.填空LFU 算法替换掉 cache 中引用 ____ 最少的块。
答案：次数
66.填空全写法写不命中时可采用 ____ 法或非写分配法。
答案：写分配（Write Allocate）
67.填空回写法写不命中时通常采用 ____ 法将主存块调入 cache 并更新单元内容。
答案：写分配
68.名词解释Cache 命中（Hit）
CPU 访问存储单元时，对应主存块已在 cache 行中且有效位=1 的情况；命中时 CPU 直接从 cache 取得数据，访问时间=Tc。
69.名词解释Cache 缺失（Miss）
CPU 访问存储单元时，对应主存块不在 cache 中（未装入或有效位=0）的情况；缺失时需从主存取块装入 cache，并访问主存，访问时间=Tc+Tm。
70.名词解释直接映射
主存每一块固定映射到唯一一个 cache 行（行号 = 主存块号 mod cache 行数）的映射方式；实现简单，但块冲突概率较高。
71.名词解释全相联映射
主存任一块可装入 cache 任意一行的映射方式；块冲突概率最低，但需比较所有 cache 行标记，硬件实现复杂。
72.名词解释组相联映射
将 cache 所有行分成若干组，每组内为全相联，组间为直接映射（组号 = 主存块号 mod 组数）；取直接映射与全相联之长，平衡速度与冲突率。
73.综合题某 cache 命中时间 Tc=2ns，主存访问时间 Tm=40ns，命中率 p=95%，求平均访问时间 Ta。
答案：
Ta = Tc + (1-p) × Tm = 2 + 0.05 × 40 = 2 + 2 = 4 ns。
74.综合题某 32KB cache、块大小 32B、采用 4 路组相联映射，求组数、标记位数（假设主存地址 32 位）。
答案：
行数 = 32KB / 32B = 1024 行；组数 = 1024 / 4 = 256 组。
地址字段：块内偏移 = log₂32 = 5 位；组索引 = log₂256 = 8 位；标记 = 32 - 8 - 5 = 19 位。
75.综合题比较直接映射、全相联映射、组相联映射三者在「地址字段」、「查找复杂度」、「块冲突概率」三方面的差异。
答案：
① 直接映射：地址 = 标记+行索引+块内；查找最简单（一次比较）；冲突概率最高。
② 全相联映射：地址 = 标记+块内（无行索引）；查找最复杂（同时比较所有行）；冲突概率最低。
③ 组相联映射：地址 = 标记+组索引+块内；查找复杂度居中（组内并行比较 2^s 行）；冲突概率介于两者之间。

第五节 虚拟存储器

25 题
76.单选CPU 中负责将虚拟地址 VA 转换为主存物理地址 PA 的部件是？
  • A. MMU（存储管理部件）
  • B. PC
  • C. IR
  • D. ID
答案：A
MMU（Memory Management Unit）完成虚实地址转换。
77.单选页式虚拟存储器中，虚拟页调入主存后存放在？
  • A. 任意虚拟地址空间
  • B. 任意空闲页框（Page Frame）
  • C. 固定页框
  • D. 磁盘固定位置
答案：B
页式虚拟存储采用「全相联」：每个虚拟页可装入主存任意一个空闲页框，由页表记录虚拟页→物理页框的映射。
78.单选页表项中「装入位（Valid）」=0 时，若存放位置字段为 null，表示？
  • A. 缓存页
  • B. 未缓存页
  • C. 未分配页
  • D. 已淘汰页
答案：C
装入位=0 + 位置=null = 未分配页；装入位=0 + 位置=外存地址 = 未缓存页；装入位=1 = 缓存页（位置=物理页框号）。
79.单选「快表（TLB）」本质上是？
  • A. 页表项的高速缓存
  • B. 数据的 cache
  • C. 寄存器集合
  • D. 硬盘缓冲区
答案：A
TLB（Translation Lookaside Buffer）= 转换后备缓冲器，缓存页表中最活跃的几个页表项；主存中的页表称为慢表。
80.单选下列「最佳」的访存组合是？
  • A. TLB 命中 + cache 命中 + 缺页
  • B. TLB 命中 + cache 缺失 + 主存命中
  • C. TLB 缺失 + cache 命中 + 主存命中
  • D. TLB 命中 + cache 命中 + 主存命中（页在主存）
答案：D
最佳：TLB 命中（快表取页表项，无需访主存取页表）+ cache 命中（无需访主存数据）+ 页在主存；最差：TLB 缺失+缺页+cache 缺失，需访问外存+多次主存。
81.单选段页式虚拟存储器的「地址转换」需几次查表？
  • A. 1 次（页表）
  • B. 2 次（先段表、再段内页表）
  • C. 3 次
  • D. 不需要查表
答案：B
段页式 = 段表 + 段内页表两级定位：①根据段号查段表得到段页表起始地址；②根据段内页号查段页表得到物理页框号。
82.单选关于虚拟存储器带来的好处，下列错误的是？
  • A. 每个进程具有一致的虚拟地址空间
  • B. 把主存看成硬盘的高速缓存，提高主存利用率
  • C. 进程地址空间私有，进程间相互保护
  • D. 主存容量因此变得无限大
答案：D
虚存是「假象」：让程序以为主存极大，但实际主存容量仍由物理硬件决定，仍可能发生缺页异常。
83.单选Linux 进程的虚拟地址空间中「内核空间」通常位于？
  • A. 0x00000000 以下
  • B. 用户空间之上、堆栈区之间
  • C. 0xc0000000 以上的高端地址
  • D. 0x08048000 起
答案：C
32 位 Linux 中内核空间在 0xc0000000 以上；用户空间在其下方，包含只读代码/数据、堆、共享库、用户栈等。
84.单选Linux 中「用户栈」的地址增长方向是？
  • A. 从高地址向低地址增长
  • B. 从低地址向高地址增长
  • C. 不增长
  • D. 双向增长
答案：A
用户栈（用户空间最高地址区域）从高地址向低地址动态增长；堆（malloc 区域）从低地址向高地址增长。
85.单选页故障处理中，若所访问的虚拟地址不在任何 vm_area_struct 描述的区域内，Linux 将产生？
  • A. 段故障（Segmentation Fault）
  • B. 缺页异常
  • C. 越权访问
  • D. TLB 缺失
答案：A
VA 落在「空洞」中（不在任何合法区域）→ 段故障；VA 落在合法区域但访问权限不符 → 越权/越级；VA 合法但页未调入 → 缺页异常。
86.填空CPU 中的 MMU 把指令中的 ____ 地址（VA）转换为主存的物理地址（PA）。
答案：逻辑（虚拟/虚）
87.填空虚拟地址空间分为「内核空间」和 ____ 空间两部分。
答案：用户
88.填空页式虚拟存储中虚拟地址由「虚拟页号」和「____」两字段组成；主存物理地址由「物理页号」和同长度的该字段组成。
答案：页内偏移地址（页内地址）
89.填空页表项中 ____ 位（脏位）用来说明对应页是否被修改过。
答案：修改
90.填空快表 TLB 是页表项的 ____ 缓存；主存中的页表称为慢表。
答案：高速（cache）
91.填空CPU 访存过程中可能发生的三种缺失：TLB 缺失、cache 缺失、____。
答案：缺页（Page Miss）
92.填空缺页由 ____ 处理；cache 缺失由硬件处理。
答案：操作系统（软件）
93.填空虚拟地址空间是主存和 ____ 存储器的抽象。
答案：硬盘（外存）
94.名词解释虚拟存储器
由 MMU 与操作系统共同实现的存储管理技术，通过页/段表把逻辑地址映射为主存物理地址，使每个进程都拥有独立的、极大的虚拟地址空间；分页/分段/段页式三种实现方式。
95.名词解释页表（Page Table）
记录进程中各虚拟页与所存放的主存页框或硬盘存储位置之间映射关系的数据结构，每个虚拟页对应一个页表项（包含存放位置、装入位、修改位、使用位、访问权限、禁止缓存位等）。
96.名词解释TLB（快表）
Translation Lookaside Buffer，转换后备缓冲器，是页表项的专用高速缓存，存放最活跃的几个页表项，MMU 优先查询快表加速地址转换；快表缺失时才访问主存中的慢表。
97.名词解释缺页（Page Fault）
CPU 访问某虚拟页时，对应页表项装入位=0 且存放位置指向外存，即页未在主存中的情况；由 OS 调出缺页异常处理程序，从外存调入该页到主存后再继续执行。
98.名词解释MMU
Memory Management Unit，存储管理部件，CPU 内部负责将虚拟地址 VA 转换为主存物理地址 PA 的硬件部件，通过查页表/TLB 完成地址转换，并检测缺页/越权等异常。
99.综合题页式虚拟存储中，MMU 进行一次「地址转换」的过程是什么？
答案：
① 根据页表基址寄存器得到页表起始地址；
② 以虚拟页号 VPN 作为索引查页表，得到对应页表项；
③ 检查页表项装入位 V：若 V=1，取出物理页号 PPN；
④ 物理地址 PA = PPN × 页大小 + 页内偏移；
⑤ 若 V=0，触发缺页异常，由 OS 调入该页后再重新执行访问。
实际中先查 TLB（快表）：TLB 命中直接取 PPN；TLB 缺失再查慢表。
100.综合题分析 TLB、cache、缺页三种缺失的 8 种组合在性能上的差异（从最优到最差排序）。
答案：
TLB 命中 + cache 命中 + 页在主存（不缺页）：最优，0 次主存访问；
TLB 命中 + cache 缺失 / TLB 缺失+cache 命中 + 页在主存：1 次主存访问；
TLB 命中 + cache 缺失 / TLB 缺失 + cache 命中 + 缺页：需 1 次主存 + 1 次外存；
TLB 缺失 + cache 缺失 + 缺页：最差，需 2 次主存 + 1 次外存，OS 调度开销巨大。

第六节 实例：Intel Core i7+Linux 存储系统

10 题
101.单选Core i7 中 L1、L2、L3 三类 cache 的大小分别为？
  • A. 8KB / 32KB / 256KB
  • B. 32KB / 256KB / 8MB
  • C. 256KB / 8MB / 32KB
  • D. 32KB / 8MB / 256KB
答案：B
Core i7：L1=32KB（指令+数据各 32KB）、L2=256KB、L3=8MB。
102.单选Core i7 中 L1 和 L2 cache 的组相联路数、L3 高速缓存的组相联路数分别为？
  • A. 4 / 8 / 16
  • B. 8 / 8 / 8
  • C. 8 / 8 / 16
  • D. 16 / 8 / 8
答案：C
Core i7 中 L1/L2 都是 8 路组相联；L3 为 16 路组相联。
103.单选Core i7 中 L1 数据 TLB、L1 指令 TLB、L2 联合 TLB 的项数分别为？
  • A. 64 / 64 / 512
  • B. 32 / 32 / 128
  • C. 64 / 128 / 512
  • D. 128 / 128 / 256
答案：A
L1 数据 TLB=64 项；L1 指令 TLB=64 项；L2 联合 TLB=512 项；都是 4 路组相联。
104.单选Core i7 中 Linux 系统的页大小通常为？
  • A. 1KB
  • B. 2KB
  • C. 4KB（页内偏移 12 位）
  • D. 4KB（但可配 4KB/2MB/1GB）
答案：D
Core i7 启动时页大小可配为 4KB / 2MB / 1GB，Linux 默认采用 4KB，页内偏移占 12 位。
105.填空Core i7 中所有核共同一个 ____ 联合 cache 和同一个 DDR3 存储器控制器。
答案：L3
106.填空Core i7 中 L1 cache 为 ____ cache（数据与指令分开），L2/L3 为联合 cache。
答案：分离
107.填空Core i7 中主存块（cache 行）大小为 ____ B。
答案：64
108.名词解释L1 / L2 / L3 多级 cache
现代 CPU 内的多级 cache 结构：L1 速度最快、容量最小、分离（指令/数据分开）；L2 容量居中、联合；L3 容量最大、联合、被所有核共享；CPU 访问顺序 L1→L2→L3→主存。
109.综合题Core i7 的一次「存储访问」大致要经过哪两个步骤？
答案：
① 通过 MMU（段式 + 页表）将虚拟地址 VA 转换为物理地址 PA；
② 根据物理地址 PA 按 L1→L2→L3→主存顺序在 cache/主存中查找数据；
若 TLB 缺失则需先查慢表；若 cache 缺失则需从主存取块并装入 cache；若发生缺页则需从外存调入页。
110.综合题Linux 中页故障处理的主要流程是什么？
答案：
① MMU 在地址转换时检测到页故障，转入 OS 内核处理；
② 内核把 VA 与 vm_area_struct 链表中各区域比较，判断是否落在「空洞」中；若是 → 段故障，终止进程；
③ 若 VA 落在合法区域但操作权限不符（写只读区、用户态访问内核区等） → 越权/越级，终止进程；
④ 否则视为正常缺页异常：在主存找空闲页框，若无则按页替换算法淘汰一页；
⑤ 从外存将缺失页装入选中的页框，更新页表与 TLB，恢复进程继续执行。
