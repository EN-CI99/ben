15名词解释
指令（instruction）
参考答案：

指令是用 0 和 1 表示的一串 0/1 序列，用来指示 CPU 完成一个特定的原子操作（如取数、存数、加、传送等）。

16名词解释
存储程序
参考答案：

冯·诺依曼结构计算机的基本工作方式：程序执行前先将指令和数据送入主存，一旦启动，计算机能在无须操作人员干预的情况下自动完成逐条指令的取出和执行。

17名词解释
总线
参考答案：

连接不同部件进行信息传输的介质，包含用于传输地址信息、数据信息和控制信息的地址线、数据线和控制线。

18名词解释
MAR / MDR（主存地址寄存器 / 主存数据寄存器）
参考答案：

CPU 访问主存时，送到地址线的主存地址先存放在MAR（主存地址寄存器）中；发送到数据线或从数据线取来的信息存放在MDR（主存数据寄存器）中。

19综合题
简述冯·诺依曼结构计算机的基本思想。
参考答案：

①采用"存储程序"工作方式；

②计算机由运算器、控制器、存储器、输入设备、输出设备五大基本部件组成；

③存储器既能存放数据也能存放指令，形式上没有区别但计算机应能区分它们；控制器应能自动执行指令；运算器能进行基本算术和逻辑运算；操作人员通过输入/输出设备使用计算机；

④计算机内部以二进制形式表示指令和数据；每条指令由操作码和地址码两部分组成，一串指令组成程序。

20综合题
简述一条指令的执行过程（分别说明顺序型指令和跳转型指令下一条指令地址的确定）。
参考答案：

每条指令的执行过程：从主存取指令 → 对指令进行译码 → PC 增量 → 取操作数并执行 → 将结果送至主存或寄存器保存。

下一条指令地址的确定：

①若当前为顺序型指令，下条指令地址 = PC 的内容 + 当前指令的长度；

②若当前为跳转型指令，下条指令地址 = 指令中指定的目标地址。

当前指令执行完后，根据 PC 的值到主存取到的就是下条将要执行的指令，因而计算机能周而复始自动取指、执行。

38综合题

④链接阶段（ld）：将多个 .o 与标准函数库中的目标文件（如 printf.o）合并，生成可执行目标文件 hello。

51名词解释
ISA（指令集体系结构）
参考答案：

软件和硬件之间接口的完整定义。ISA 定义了一台计算机可执行的所有指令的集合、每条指令执行什么操作、所处理操作数存放的地址空间以及操作数类型。

52名词解释
ABI（应用程序二进制接口）
参考答案：

为运行在特定 ISA 及特定操作系统平台上的应用程序规定的一种机器级目标代码接口，包含生成特定平台目标代码时必须遵循的约定。描述了应用程序与操作系统、库及各组成部分之间较低层次的机器级代码接口。

53名词解释
API（应用程序编程接口）
参考答案：

定义较高层次的源程序代码和库之间的接口，通常是与硬件无关的接口。

54名词解释
未定义行为
参考答案：

语言标准规范中没有明确指定其行为的情况。若编写了含未定义行为的源程序，则每次执行结果可能不同，或在不同平台下执行结果可能不同。

55综合题
简述 ISA、ABI、API 三者的区别与联系，以及它们在计算机系统层次结构中的位置。
参考答案：

ISA：软件和硬件之间的接口，定义机器指令集（所有指令集合、操作、操作数地址空间和类型）；

ABI：特定 ISA + 特定 OS 平台上应用程序的机器级目标代码接口，描述应用程序与操作系统、库及各组成部分之间低层次的机器级代码接口；

API：较高层次源程序代码与库之间的接口，通常与硬件无关。

层次位置（自上而下）：API（高层）→ ABI（机器级）→ ISA（软硬件界面）→ 硬件。

56综合题
简述编译程序前端和后端分别遵循什么规范，以及导致"程序执行结果不符合预期"的三种行为。
参考答案：

前端：按高级编程语言标准规范设计（词法分析、语法分析、语义分析、中间代码生成）；

后端：按 ISA 和 ABI 规范设计（代码优化、目标代码生成、目标代码优化）。

三种行为：

①未定义行为——标准未指定，每次执行或不同平台结果可能不同；

②未指定行为——标准列出多种结果供编译器选择，不同编译器结果可能不同；

③实现定义行为——实现需在文档中说明所选行为，同环境结果相同，移植后可能不同。

70名词解释
吞吐率（Throughput）
参考答案：

单位时间内所完成的工作量，类似的概念是带宽（Bandwidth，单位时间内所传输的信息量）。

71名词解释
响应时间（Response Time）
参考答案：

从作业提交开始到作业完成所用的时间，类似的概念是执行时间（Execution Time）和等待时间（Latency）。

72名词解释
CPI
参考答案：

执行一条指令所需的时钟周期数。对特定指令是确定值；对程序或机器而言是全部指令执行所需的平均时钟周期数，称综合 CPI。

73名词解释
MIPS（Million Instructions Per Second）
参考答案：

平均每秒钟执行多少百万（10⁶）条指令，用于衡量机器执行定点指令的速度。

74综合题
某程序在某计算机上运行，程序共含 1000 条指令，综合 CPI 为 2，CPU 主频为 2 GHz。求：(1) 程序的总时钟周期数；(2) CPU 执行时间；(3) 该机器的 MIPS。
参考答案：

(1) 总时钟周期数 = 指令条数 × CPI = 1000 × 2 = 2000

(2) CPU 执行时间：主频 2 GHz 时钟周期 = 1/(2×10⁹) = 0.5 ns；执行时间 = 2000 × 0.5 ns = 1000 ns = 1 μs

(3) MIPS = 指令条数 / (执行时间(秒) × 10⁶) = 1000 / (10⁻⁶ × 10⁶) = 1000 MIPS

（也可用公式 MIPS = 主频 / (CPI × 10⁶) = 2×10⁹ / (2×10⁶) = 1000）

75综合题
某程序包含 3 类指令：A 类 500 条、CPI=1；B 类 300 条、CPI=2；C 类 200 条、CPI=4。求：(1) 程序总指令条数；(2) 程序综合 CPI；(3) 若主频为 1 GHz，CPU 执行时间。
参考答案：

(1) 总指令条数 = 500 + 300 + 200 = 1000

(2) 综合 CPI：总时钟周期数 = 500×1 + 300×2 + 200×4 = 500 + 600 + 800 = 1900；综合 CPI = 1900 / 1000 = 1.9

(3) CPU 执行时间：主频 1 GHz 时钟周期 = 1 ns；执行时间 = 1900 × 1 ns = 1900 ns = 1.9 μs
