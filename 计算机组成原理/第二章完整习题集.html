14名词解释

15名词解释

参考答案：

16名词解释

参考答案：

由符号位直接跟数值位构成，符号位 0 表示正数、1 表示负数；正数和负数的编码仅符号位不同，数值部分完全相同。

参考答案：

18综合题
将十进制数 25.125 转换成二进制数。
参考答案：

整数部分：25 = 11001（除基取余：25÷2 余 1，12÷2 余 0，6÷2 余 0，3÷2 余 1，1÷2 余 1，自下而上为 11001）；

小数部分：0.125×2=0.25 取 0，0.25×2=0.5 取 0，0.5×2=1.0 取 1，故 0.125 = 0.001；

结果：25.125 = 11001.001。

19综合题
设 8 位二进制数 x 的真值为 -13，求 [x]原、[x]反、[x]补。
参考答案：

|13| = 00001101；

原码：符号位 1 + 数值位 → 10001101；

反码：符号位不变，数值位取反 → 11110010；

补码：反码末位 +1 → 11110011。

33综合题
已知某 8 位补码为 1111 1110，求其真值。
参考答案：

最高位为 1，是负数。数值部分先取反后 +1：1111 1110 → 除符号位取反得 0000 0001 → +1 得 0000 0010 = 2。

故真值为 -2。

48综合题
简述浮点数的规格化操作（左规和右规），并说明各自对阶码的影响。
参考答案：

右规：当有效数位进到小数点前面时，尾数每右移一位，阶码加 1，直到尾数变成规格化形式；右规时阶码会增加，因此阶码有可能溢出。

左规：当结果形如 ±0.0…0bb…b×2ᴱ 时，尾数每左移一位，阶码减 1，直到尾数变成规格化形式。

参考答案：

原码除法算法：若中间余数为正则上商 1、下次做减法，若为负则上商 0、下次做加法，每次循环步骤规整，故称加减交替法。

105综合题
简述无符号数除法的运算步骤（算法要点）。
参考答案：

①操作数预置：确认被除数、除数都不为 0 后，将被除数置于余数寄存器 R 和余数/商寄存器 Q，除数置于除数寄存器 Y；

②做减法试商：根据 R-Y 结果的符号判断大小，为正则上商 1，为负则上商 0；

③恢复余数：上商为 0 时把减掉的除数再加回来；

④中间余数左移：除数不动，中间余数和商一起左移，Q 最低位空出以备上商。

120综合题
简述浮点数加减法的完整运算步骤。
参考答案：

①对阶：小阶向大阶看齐，阶小的数尾数右移；

②尾数加减：还原隐藏位，附加位参与运算，做定点原码小数加减；

③尾数规格化：±1b.bb…b 右规（尾数右移、阶码加 1），±0.00…01b…b 左规（尾数左移、阶码减 1）；

④尾数舍入处理：就近舍入 / 朝 ±∞ / 朝 0 方向；

⑤阶的溢出判断：结果是否溢出主要看阶是否上溢。
