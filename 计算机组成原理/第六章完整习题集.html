第一节 I/O 子系统概述

14 题
1.单选I/O 子系统主要解决？
  • A. CPU 与主存的速度匹配
  • B. 信息的输入/输出，即如何通过外设将信息输入计算机或从计算机输出给用户
  • C. 程序的链接与加载
  • D. 指令译码与执行
答案：B
I/O 子系统解决信息输入/输出问题，包含 I/O 软件与 I/O 硬件两大部分。
2.单选I/O 软件的两个层次是？
  • A. 应用层 + 驱动层
  • B. 系统层 + 硬件层
  • C. 用户空间 I/O 软件 + 内核空间 I/O 软件（系统 I/O 软件）
  • D. 字符设备 + 块设备
答案：C
用户空间 I/O 软件（用户态，向上层用户程序提供 I/O 请求接口）+ 内核空间 I/O 软件（系统 I/O 软件，分三层：与设备无关层、设备驱动层、中断服务程序层）。
3.单选系统 I/O 软件（内核空间 I/O 软件）分为哪三个层次？
  • A. 与设备无关 I/O 软件层 + 设备驱动程序层 + 中断服务程序层
  • B. 用户 I/O + 系统 I/O + 硬件 I/O
  • C. 文件系统 + 缓存层 + 通用块设备层
  • D. 字符设备 + 块设备 + 网络设备
答案：A
系统 I/O 软件三层：①与设备无关 I/O 软件层；②设备驱动程序层；③中断服务程序层。
4.单选用户进程通过「陷阱指令」陷入内核态后，CPU 根据哪个寄存器中的「系统调用号」选择相应服务例程？
  • A. EBX
  • B. ECX
  • C. EDX
  • D. EAX
答案：D
Linux 系统调用约定：系统调用号放在 EAX 中，参数依次为 EBX/ECX/EDX/ESI/EDI。
5.单选Linux 中 write(fd, buf, n) 函数的返回类型为何是 ssize_t 而不是 size_t？
  • A. 因为返回字节数可能为负
  • B. 因为正常返回实际写入字节数（≥0），错误时返回 -1，需要带符号 int
  • C. 因为系统调用开销太大
  • D. 因为历史遗留
答案：B
返回值 = 实际写入字节数（非负）或 -1（出错），必须用带符号 int（ssize_t）才能表示 -1。
6.单选I/O 操作完成后由外设触发，CPU 接下来调出哪个程序执行以完成数据交换？
  • A. 应用程序本身
  • B. 系统调用服务例程
  • C. 中断服务程序
  • D. 引导程序
答案：C
外设就绪后发中断请求，CPU 响应中断并调出对应的中断服务程序，在中断服务程序中完成数据交换。
7.填空I/O 软件包括最上层提出 I/O 请求的「用户 I/O 软件」和底层操作系统对 I/O 进行具体管理和控制的「____ I/O 软件」。
答案：系统
8.填空Linux 中 write(fd, buf, n) 函数中的参数 n 表示要写的 ____。
答案：字节数
9.填空CPU 在用户态执行到系统调用封装函数对应的指令序列中的 ____ 指令时，会从用户态陷入内核态。
答案：陷阱
10.填空系统 I/O 软件分三个层次：与设备无关的 I/O 软件层、____ 层、中断服务程序层。
答案：设备驱动程序
11.名词解释I/O 子系统
计算机系统中负责信息输入/输出的部分，由 I/O 软件（用户空间 I/O 软件 + 内核空间 I/O 软件）和 I/O 硬件（外设与设备控制器）组成，采用层次结构实现对外设的统一管理与控制。
12.名词解释系统调用（System Call）
用户进程通过陷阱指令进入内核态，请求操作系统内核提供服务的接口机制；用户态与内核态之间通过系统调用实现受控的切换，每次系统调用涉及两次上下文切换，开销较高。
13.名词解释设备控制器（Device Controller）
位于 I/O 设备与系统总线之间的硬件部件，负责接收主机的命令并控制外设完成具体 I/O 操作；提供数据缓冲、错误/就绪检测、控制/定时、数据格式转换等功能。
14.综合题简述一次 I/O 操作中从用户进程发起 write 调用到数据最终写入外设的完整过程（贯穿 I/O 软件与硬件各层）。
答案：
① 用户进程在用户态调用 write 库函数/封装函数；
② 封装函数执行陷阱指令，CPU 从用户态陷入内核态，根据 EAX 中的系统调用号选择 write 服务例程；
③ 内核中与设备无关的 I/O 软件层检查参数、定位文件描述符对应的设备；
④ 调用具体设备的驱动程序，驱动程序初始化设备控制器并启动外设；
⑤ 外设准备好接收数据后发出中断请求；
⑥ CPU 响应中断调出对应的中断服务程序，在其中完成与外设的数据交换；
⑦ 中断返回，write 服务例程返回写入字节数，CPU 切回用户态，进程继续执行。

第二节 用户空间 I/O 软件

25 题
15.单选在 UNIX/Linux 中，对「所有 I/O 操作」的设计哲学是？
  • A. 所有 I/O 操作都通过读写文件实现，所有外设都被视为文件
  • B. 只有磁盘文件才是文件
  • C. 网络设备单独管理
  • D. 字符设备与块设备分开管理
答案：A
UNIX 中所有 I/O 都通过读写文件实现，socket、终端等都被视为文件；「一切皆文件」。
16.单选UNIX 中「文件」的抽象定义是？
  • A. 一组有结构的数据记录
  • B. 磁盘上的目录项
  • C. 一组磁盘块
  • D. 一个字节序列
答案：D
UNIX 把文件定义为一个字节序列（byte sequence），对所有 I/O 设备统一为字节流接口。
17.单选下列哪种「不是」ASCII 文件（文本文件）？
  • A. C 源程序文件
  • B. 终端标准输入文件
  • C. 可重定位目标文件（.o）
  • D. 标准输出文件
答案：C
.o 可重定位文件是二进制文件；源程序 .c、终端 stdin/stdout 是 ASCII 文本文件。
18.单选open 函数成功打开文件时返回？
  • A. 文件首地址
  • B. 一个非负整数文件描述符
  • C. -1
  • D. 0
答案：B
成功返回非负整数（文件描述符 fd），失败返回 -1。
19.单选C 标准 I/O 库函数中「全缓冲 _IOFBF」的特点是？
  • A. 遇换行符也不写文件，只有缓冲区满时才真正写入
  • B. 遇换行符即写入文件
  • C. 不经过缓冲直接写入
  • D. 写完一个字节即刷新
答案：A
全缓冲：仅在缓冲区满时刷新；行缓冲：遇换行符或缓冲区满刷新；非缓冲：直接写文件。普通文件默认为全缓冲。
20.单选C 标准 I/O 库函数中「流缓冲区」的主要目的是？
  • A. 让程序运行更快
  • B. 简化文件操作
  • C. 减少系统调用次数
  • D. 增加安全性
答案：C
流缓冲区使得多次小数据 read/write 可合并为一次底层系统调用，从而显著减少开销。
21.单选stdin、stdout、stderr 对应的文件描述符 fd 分别为？
  • A. 0、1、2
  • B. 1、2、3
  • C. 0、1、3
  • D. 1、0、2
答案：A
stdin=0, stdout=1, stderr=2，对应 _iob 数组前 3 项。
22.单选getc 宏只在何种情况下会调用 _fillbuf 填充缓冲区？
  • A. 每次都调用
  • B. 每 1024 次调用一次
  • C. cnt=0 时
  • D. cnt 减 1 后为负数（缓冲区已空）时
答案：D
getc 多数情况只改 cnt 与 ptr；只有 cnt-- 后为负，才调用 _fillbuf 触发一次 read 系统调用填充缓冲区。
23.单选关于标准 I/O 库函数「不足」的描述，错误的是？
  • A. I/O 为同步操作，程序必须等待 I/O 完成
  • B. C 标准库不提供读取文件元数据的函数
  • C. 网络编程中容易出现缓冲区溢出
  • D. 标准 I/O 库函数在所有平台上都不可移植
答案：D
标准 I/O 库函数反而「移植性好」；不足是同步、缺元数据、网络风险、不支持加锁等。
24.填空ASCII 文件也称为 ____ 文件，由多个正文行组成，每行以 '\n' 结束。
答案：文本
25.填空在 UNIX 系统中，文件就是一个 ____ 序列。
答案：字节
26.填空UNIX 中使用 lseek 函数设置文件的 ____ 位置，初始为 0。
答案：读写
27.填空关闭文件时系统会释放文件相关数据结构所在的存储区并回收 ____。
答案：文件描述符（fd）
28.填空系统级 I/O 函数中对文件的标识是 ____，而 C 标准 I/O 库函数中对文件的标识是 FILE 结构指针 fp。
答案：文件描述符（fd）
29.填空C 标准 I/O 库函数默认 BUFSIZ 大小为 ____ 字节。
答案：1024
30.填空每次系统调用都要进行两次上下文切换，先从用户态切到内核态，处理后再从内核态切回 ____ 态。
答案：用户
31.填空普通文件的流缓冲区属性默认为 ____ 缓冲。
答案：全（_IOFBF）
32.填空Windows 中文件 I/O API 函数包括 CreateFile、ReadFile、WriteFile、CloseHandle 等。
答案：CloseHandle（关闭文件句柄）
33.名词解释文件描述符（fd）
操作系统为每个被打开的文件分配的一个非负整数标识，用于在系统级 I/O 函数中指代该文件；stdin/stdout/stderr 默认为 0/1/2。
34.名词解释流（Stream）
C 标准 I/O 库中对已打开文件的抽象，用 FILE 结构体描述；包括流缓冲区、当前读写位置、文件描述符等状态。
35.名词解释ASCII 文件
由多个以换行符 '\n' 结束的正文行组成、每个字节是一个可读 ASCII 字符的文本文件；与可重定位/可执行文件等二进制文件相对。
36.名词解释全缓冲（_IOFBF）
C 标准 I/O 的一种缓冲属性：仅当缓冲区满时才将缓冲内容真正写入文件；即使遇到换行符也不立即刷新；普通文件默认采用全缓冲。
37.名词解释行缓冲（_IOLBF）
C 标准 I/O 的一种缓冲属性：遇换行符或缓冲区满时立即将缓冲内容写入文件；通常用于终端等交互设备。
38.综合题说明 C 标准 I/O 库函数如何利用流缓冲区显著减少 read 系统调用次数。
答案：
① 第一次调用 getc 时触发 _fillbuf，通过 malloc 建立 1024B 缓冲区，并执行 1 次 read 系统调用读入最多 1024 字节；
② 后续 1023 次 getc 调用仅修改缓冲区指针 ptr 和剩余计数 cnt，不再触发系统调用；
③ 当 cnt 减为 0/负时再次调用 _fillbuf 填充下一批 1024 字节；
④ 对 n 次连续 getc 操作：使用 C 标准 I/O 仅约 ⌈n/1024⌉ 次系统调用，而直接调用 read 每次读 1 字节则需 n 次系统调用；
⑤ 通过流缓冲把多个用户态 I/O 合并为少量系统调用，显著降低了用户态/内核态切换开销。
39.综合题比较「系统级 I/O 函数」与「C 标准 I/O 库函数」在标识方式、调用开销、移植性、I/O 同步性、缓冲机制上的差异。
答案：
① 标识：系统级用 fd（int），标准库用 FILE* 指针；
② 开销：系统级每次都是一次系统调用（两次上下文切换），开销大；标准库通过流缓冲减少系统调用次数；
③ 移植性：系统级函数因平台而异（如 Windows 没有 creat/read/write 等），标准库函数跨平台；
④ 同步性：两者都是同步 I/O，必须等待 I/O 完成；
⑤ 缓冲：系统级无用户态缓冲（仅有内核缓冲），标准库有用户态流缓冲区（全/行/非）。

第三节 内核空间 I/O 软件

18 题
40.单选关于「程序直接控制 I/O 方式」描述错误的是？
  • A. CPU 与外设可完全并行工作
  • B. 实现简单，设备控制电路简单
  • C. CPU 需要不断查询设备状态寄存器
  • D. 外设速度远慢于 CPU 时 CPU 时间被严重浪费
答案：A
程序直接控制下 CPU 必须忙等待（轮询设备状态寄存器），不能并行工作；选项 A 错。
41.单选「中断控制 I/O 方式」下，CPU 启动外设后？
  • A. 阻塞等待外设完成
  • B. 可调度其他进程运行，外设完成后通过中断通知 CPU
  • C. 直接进行数据传送
  • D. 关闭中断
答案：B
中断方式：CPU 启动外设后调度其他进程执行，外设就绪后发中断请求，CPU 响应中断再处理 I/O。
42.单选DMA 控制器每完成一个数据的传送后？
  • A. 立即终止传送
  • B. 给 CPU 发送数据中断
  • C. 字计数器减 1 并更新主存地址
  • D. 不做任何事
答案：C
DMA 控制器每完成 1 个数据：字计数器 -1、主存地址 +数据宽度；全部完成时发「DMA 结束」中断。
43.单选DMA 控制 I/O 方式下，CPU 介入 I/O 的时机是？
  • A. 每个数据传送时
  • B. 不介入
  • C. 仅在数据传送结束
  • D. 仅在 DMA 初始化阶段和「DMA 结束」中断处理时
答案：D
DMA 方式下数据传送过程完全由 DMA 控制器在硬件中完成，CPU 仅介入初始化与结束中断两次，开销极小。
44.单选中断服务程序通常分几个阶段？
  • A. 3 阶段：准备阶段、处理阶段、恢复阶段
  • B. 2 阶段：响应阶段、处理阶段
  • C. 4 阶段：响应、保护、处理、返回
  • D. 5 阶段
答案：A
中断服务程序三阶段：①准备（保存现场、新屏蔽字、开中断）；②处理（读中断号、调用具体服务、通知设备、清除中断）；③恢复（关中断、恢复现场/旧屏蔽字、iret 返回）。
45.单选「中断屏蔽字」通常存放在？
  • A. CPU 通用寄存器
  • B. 中断控制器中的一个 I/O 端口
  • C. 主存固定区域
  • D. 高速缓存
答案：B
中断屏蔽字寄存器是中断控制器中的一个 I/O 端口，由 CPU 通过 I/O 指令设置；每位对应一个中断源。
46.单选「通用块设备 I/O 层」的主要作用是？
  • A. 屏蔽所有 I/O 设备
  • B. 直接控制字符设备
  • C. 为所有块设备（磁盘/SSD/光盘）提供统一抽象（统一逻辑块大小）
  • D. 实现 DMA 传送
答案：C
通用块设备层把磁盘/SSD/光盘等块设备的扇区大小差异屏蔽，对上层文件系统呈现统一的逻辑块大小。
47.填空三种 I/O 控制方式为：程序直接控制 I/O、____ 控制 I/O、DMA 控制 I/O。
答案：中断
48.填空DMA 控制器每完成 1 个数据传送后将字计数器 ____ 并更新主存地址。
答案：减 1
49.填空中断服务程序中若允许后续处理中响应其他中断，则在准备阶段应：保存旧屏蔽字、设置新屏蔽字、并 ____ 中断。
答案：开（打开）
50.填空CPU 在中断处理过程中被新的更高优先级中断请求打断并转去处理新中断的现象称为 ____ 中断（也称中断嵌套）。
答案：多重
51.填空与设备无关的 I/O 软件层包含三个组件：文件系统、缓存层、____ I/O 层。
答案：通用块设备
52.填空设备驱动程序在初始化时会向操作系统注册相应的中断服务，并把 ____ 号作为参数指示中断服务绑定。
答案：中断
53.名词解释设备驱动程序（Device Driver）
操作系统内核中负责控制具体 I/O 设备工作的软件，包含设备初始化、I/O 启动、状态查询、中断服务注册等；其实现与具体设备的 I/O 控制方式（程序查询/中断/DMA）紧密相关。
54.名词解释DMA 控制器
专门用于在外设与主存之间直接进行批量数据传送的硬件接口，数据不经过 CPU；内部有字计数器和地址寄存器，每传送 1 个数据自动减 1 并更新地址，全部完成时发 DMA 结束中断。
55.名词解释中断屏蔽字
存放在中断控制器中的一位一字位串，每位对应一个外设中断源；通常 1 表示允许该中断源打断当前中断处理，0 表示屏蔽；软件可通过指令修改屏蔽字，动态改变中断处理次序。
56.名词解释多重中断（中断嵌套）
CPU 在执行某中断服务程序时，被新的（通常更高优先级）中断请求打断并转去处理新中断的现象；通过中断屏蔽字实现允许/禁止哪些中断可打断当前处理。
57.综合题比较程序直接控制、中断控制、DMA 控制三种 I/O 方式在「CPU 介入程度」「外设与 CPU 能否并行」「硬件复杂度」「适用场景」上的差异。
答案：
① 程序直接控制：CPU 全程忙等待；外设与 CPU 不能并行；硬件最简单（仅状态/数据端口）；适用于简单嵌入式/极低速外设；
② 中断控制：CPU 仅在中断时介入；外设与 CPU 可并行；硬件中等（需中断控制器）；适用于一般字符设备/中低速块设备；
③ DMA 控制：CPU 仅在初始化与结束中断时介入；外设与 CPU 完全并行；硬件最复杂（DMA 控制器）；适用于磁盘/高速块设备。

第四节 I/O 硬件与软件的接口

21 题
58.单选下列哪类「不是」块设备？
  • A. 磁盘驱动器
  • B. 键盘
  • C. 固态硬盘（SSD）
  • D. 光盘
答案：B
键盘是字符设备（按字符流传送）；磁盘/SSD/光盘都是块设备（按固定大小数据块寻址）。
59.单选块设备的核心特征是？
  • A. 按字符流传输
  • B. 不可寻址
  • C. 以固定大小数据块为单位与主机交换信息且可寻址
  • D. 只能顺序访问
答案：C
块设备：固定大小数据块（≥512B）、按块寻址、可随机访问；典型如磁盘/SSD。
60.单选QPI 总线带宽计算公式「每秒传输次数 × 每次传输有效数据 × 2」中「×2」的原因是？
  • A. QPI 链路同时支持双向传输（发送+接收）
  • B. 每次传输 2 个字节
  • C. 频率翻倍
  • D. 双倍冗余
答案：A
QPI 是高速点对点双向连接，同时支持发送与接收两个方向，因此总带宽按 2 倍计算。
61.单选PCI-e 1.0 规范下「每方向」发送/接收速率为？
  • A. 1.25 Gb/s
  • B. 2 Gb/s
  • C. 2.5 Gb/s × 2
  • D. 2.5 Gb/s
答案：D
PCI-e 1.0 每方向 2.5 Gb/s；总带宽 = 2.5 Gb/s × 2 × 通路数 / 10（GB/s）。
62.单选「独立编址方式」下，CPU 访问 I/O 端口需要？
  • A. 用普通访存指令
  • B. 专门的 I/O 指令
  • C. DMA 控制器
  • D. 中断服务程序
答案：B
独立编址：I/O 地址空间与主存地址空间分开，CPU 必须用专门的 IN/OUT 等 I/O 指令访问 I/O 端口。
63.单选「统一编址（存储器映射）」方式下，CPU 访问 I/O 端口用？
  • A. 普通访存指令
  • B. 专门的 I/O 指令
  • C. 缓存旁路指令
  • D. 特权指令
答案：A
统一编址：I/O 端口与主存共用地址空间，按地址范围区分；普通访存指令即可访问 I/O 端口；大多数 RISC 采用。
64.单选下列哪项「不属于」I/O 接口（设备控制器）的主要功能？
  • A. 数据缓冲
  • B. 错误和就绪检测
  • C. 虚拟地址到物理地址的转换
  • D. 数据格式转换
答案：C
I/O 接口四大功能：数据缓冲、错误/就绪检测、控制/定时、数据格式转换；地址转换由 MMU 负责，与 I/O 接口无关。
65.单选CPU 响应中断请求后保存的「断点」是？
  • A. 当前指令地址
  • B. 中断向量
  • C. 中断服务程序首地址
  • D. 下一条指令地址
答案：D
CPU 在一条指令执行完才检测中断请求，因此断点 = 下一条指令地址；现场 = 通用寄存器等被中断时的状态。
66.填空I/O 设备分为 ____ 设备和块设备两大类。
答案：字符
67.填空早期 Intel 处理器的处理器总线称为 ____ 总线（FSB），是主板上最快的总线。
答案：前端
68.填空第三代的 I/O 总线是 ____（可简写为 PCI-e）。
答案：PCI-Express
69.填空I/O 接口（设备控制器）内用于暂时存放与主机交换的数据的寄存器称为数据 ____ 寄存器。
答案：缓冲
70.填空I/O 端口的两种编址方式是：独立编址方式和 ____ 编址方式。
答案：统一（存储器映射）
71.填空统一编址将 I/O 端口映射到主存空间的某段地址，因此也称为 ____ 映射方式。
答案：存储器（内存）
72.填空中断屏蔽字中每一位对应一个外设中断源，通常 ____ 表示允许中断，0 表示屏蔽。
答案：1
73.名词解释I/O 端口
设备控制器中可被 CPU 寻址访问的寄存器，包括数据缓冲寄存器（数据端口）、状态/控制寄存器（状态/控制端口）；所有 I/O 端口编号组成 I/O 地址空间。
74.名词解释独立编址
I/O 端口单独编号形成与主存地址空间独立的 I/O 地址空间；CPU 访问 I/O 端口需要专门的 I/O 指令（如 x86 的 IN/OUT）；x86 采用该方式。
75.名词解释统一编址（存储器映射 I/O）
将 I/O 端口与主存单元在同一个地址空间中统一编址，主存地址空间分出一部分给 I/O 端口；CPU 用普通访存指令即可访问 I/O 端口；大多数 RISC 架构采用。
76.名词解释QPI 总线
QuickPath Interconnect，Intel 处理器之间的点对点高速互连协议，基于包传输、差分信号与专用时钟；带宽 = 每秒传输次数 × 每次传输有效数据 × 2（双向）。
77.综合题比较「独立编址」与「统一编址」在「地址空间」「指令需求」「地址区分方式」「典型架构」「优缺点」上的差异。
答案：
① 地址空间：独立=独立 I/O 空间；统一=与主存共用；
② 指令：独立=需专用 I/O 指令；统一=普通访存指令即可；
③ 区分：独立=靠指令类型区分；统一=靠地址范围区分；
④ 典型架构：独立=x86；统一=大多数 RISC（MIPS/ARM/RISC-V）；
⑤ 优缺点：独立可同时使用全部主存空间但需专门指令；统一编程简单但占用部分主存地址空间。
78.综合题若某系统采用 PCI-e 1.0 ×4 通路，按规范计算其总带宽（GB/s）。
答案：
总带宽 = 2.5 Gb/s × 2（双向） × 4（通路数） / 10 = 2 GB/s。
