第一节 可执行文件生成概述

17 题
1.单选将 C 源程序转换为可执行文件的过程中，「预处理」阶段由哪个程序完成？
  • A. cpp（C Preprocessor）
  • B. ccl（编译器）
  • C. as（汇编器）
  • D. ld（链接器）
答案：A
预处理由 cpp（C Preprocessor）完成，主要处理 #include、#define、条件编译等命令。
2.单选GCC 中「只预处理不编译」对应的命令选项是？
  • A. gcc -S
  • B. gcc -c
  • C. gcc -E
  • D. gcc -o
答案：C
-E 只预处理；-S 编译到汇编；-c 汇编到可重定位目标文件；-o 指定输出文件名。
3.单选汇编器生成的「机器语言目标文件」通常称为？
  • A. 可执行目标文件
  • B. 可重定位目标文件
  • C. 共享库文件
  • D. 文本文件
答案：B
汇编生成的是「可重定位目标文件」（.o），因为单模块的指令/数据最终地址尚未确定，需要链接器重定位。
4.单选下列哪个不是链接器完成的主要任务？
  • A. 符号解析
  • B. 重定位
  • C. 合并可重定位目标文件
  • D. 词法分析
答案：D
词法分析由编译器前端完成，链接器只做「符号解析 + 重定位」。
5.单选编译时 GCC 默认产生的汇编语言源文件后缀是？
  • A. .o
  • B. .i
  • C. .s
  • D. .c
答案：C
预处理 .i → 编译 .s → 汇编 .o → 链接 可执行文件。
6.单选链接器 ld 使用的命令格式，下列哪个能直接把两个 .o 文件链接为可执行文件？
  • A. ld -o test main.o test.o
  • B. ld main.o test.o test
  • C. ld -c main.o test.o
  • D. ld main.c test.c
答案：A
-o 指定输出文件名，ld 接受 .o 而不接受 .c。
7.单选符号解析的本质是？
  • A. 确定每条指令长度
  • B. 把符号引用与符号定义建立关联
  • C. 把机器指令翻译为汇编指令
  • D. 把数据从小端转为大端
答案：B
符号解析的目的：让每个符号的引用都能关联到一个确定的符号定义。
8.填空C 源程序生成可执行文件的四个步骤依次是：预处理 → ____ → 汇编 → ____。
答案：编译；链接
9.填空GCC 中 gcc -S 对应的是 ____ 阶段，生成扩展名为 ____ 的汇编语言源文件。
答案：编译；.s
10.填空汇编程序生成的机器语言目标文件由于指令和数据地址尚未确定，故称为 ____ 目标文件。
答案：可重定位
11.名词解释链接器（Linker）
将多个可重定位目标文件以及库例程组合起来，生成可执行目标文件的程序，主要完成符号解析和重定位两项任务。
12.名词解释符号解析（Symbol Resolution）
链接器把每个模块中引用的符号（外部函数名、外部变量名）与某个目标模块中的符号定义建立关联的过程。
13.名词解释重定位（Relocation）
链接器合并所有可重定位目标文件后，根据符号在虚拟地址空间中的新地址，修改每个符号引用处地址的过程，包含「节的合并定位」和「引用地址修改」两步。
14.综合题已知某 C 源文件 main.c 中调用了在 test.c 中定义的函数 add()，请按 GCC 处理流程写出从源码到可执行文件的完整过程，并指出每一步的产物后缀。
答案：
① 预处理（cpp / gcc -E）：main.c → main.i；test.c → test.i
② 编译（ccl / gcc -S）：main.i → main.s；test.i → test.s
③ 汇编（as / gcc -c）：main.s → main.o；test.s → test.o（可重定位目标文件）
④ 链接（ld / gcc -o）：main.o + test.o → test（可执行目标文件），期间完成「符号解析」（把 main.o 中 add 的引用与 test.o 中 add 的定义关联）和「重定位」（修改 call 指令中的目标地址）。
15.综合题为什么单个模块的汇编结果不能直接运行，而要先经过链接？
答案：
单个模块在汇编时，编译器无法确定本模块中引用的外部符号（如 printf、其他模块的函数和全局变量）在最终可执行文件中的实际地址，因此其代码区、数据区都是从地址 0 开始的「待定状态」，即「可重定位目标文件」。只有经过链接器的符号解析（找到外部符号的定义）和重定位（修改所有引用处的地址），才能把所有模块拼合成地址确定的可执行文件。
16.填空链接器主要完成 ____ 和 ____ 两个任务。
答案：符号解析；重定位
17.填空可重定位文件中的代码区和数据区都是从地址 ____ 开始的。
答案：0

第二节 目标文件格式

22 题
18.单选Linux / UNIX 平台主要使用的目标文件格式是？
  • A. PE
  • B. COFF
  • C. ELF
  • D. Mach-O
答案：C
ELF（Executable and Linkable Format）= 可执行可链接格式，Linux/BSD 默认；Windows 使用 PE；macOS 使用 Mach-O。
19.单选ELF 头位于目标文件的什么位置？
  • A. 文件起始位置
  • B. 文件结尾
  • C. 程序头表之后
  • D. .text 节之后
答案：A
ELF 头固定位于文件起始，包含文件类型、机器类型、节头表偏移等元信息。
20.单选32 位系统对应的 ELF 头数据结构 Elf32_Ehdr 大小为？
  • A. 32B
  • B. 52B
  • C. 64B
  • D. 128B
答案：B
Elf32_Ehdr 共 52B；Elf64_Ehdr 共 64B，结构类似。
21.单选ELF 文件开头用于识别文件类型的几个字节称为？
  • A. 标识符
  • B. 版本号
  • C. 签名
  • D. 魔数
答案：D
Magic Number，开头几个字节用来确认文件类型/格式是否正确。
22.单选ELF 可执行目标文件比可重定位目标文件多了一个关键表，称为？
  • A. 程序头表（段头表）
  • B. 节头表
  • C. 符号表
  • D. 重定位表
答案：A
可执行文件额外有「程序头表 / 段头表」描述各段到虚拟地址空间的映射；可重定位文件只有节头表。
23.单选可执行文件中 .init 节的用途是？
  • A. 存放已初始化全局变量
  • B. 定义 main 函数
  • C. 定义 init 函数，用于程序进入 main 前的初始化
  • D. 存放动态链接信息
答案：C
.init 节包含 init 函数，系统在进入 main 之前会先执行；.fini 节则在程序退出时执行收尾。
24.单选可执行文件相比可重定位文件，「少了」下面哪个节？
  • A. .text
  • B. .rel.text
  • C. .rodata
  • D. .data
答案：B
可执行文件中指令/数据已被重定位，故可去掉 .rel.text、.rel.data 等重定位节。
25.单选i386 System V ABI 中，只读代码段在 Linux 进程虚拟地址空间中的起始地址是？
  • A. 0x00000000
  • B. 0x08048000
  • C. 0x08048000（实际值常用 0x08048000）
  • D. 0xFFFFFFFF
答案：C
i386 System V ABI 规定只读代码段起始虚拟地址 = 0x08048000。
26.单选.bss 节对应的存储区域在程序运行时会被初始化为？
  • A. 0
  • B. 随机值
  • C. 1
  • D. -1
答案：A
.bss 存放未初始化或初值为 0 的全局/静态变量，运行时由系统自动清零；文件本身不占空间。
27.单选关于运行时堆与用户栈的地址增长方向，正确的是？
  • A. 堆向低地址、栈向高地址增长
  • B. 都向高地址增长
  • C. 都向低地址增长
  • D. 堆向高地址、栈向低地址增长
答案：D
Linux 中堆区（malloc）向高地址增长；用户栈从最大地址向低地址增长。
28.单选节头表中每个表项描述的是？
  • A. 每个符号的地址
  • B. 每个节的名称、偏移、大小、对齐方式等信息
  • C. 程序的入口点
  • D. 每个段的起始地址
答案：B
节头表（Section Header Table）的每个表项描述对应节的元信息。
29.填空ELF 全称是 Executable and ____ Format，即可执行可链接格式。
答案：Linkable
30.填空节头表由若干表项组成，每个表项描述对应节的 ____、在文件中的偏移、大小、对齐方式等信息。
答案：节名
31.填空可执行文件中所有代码位置连续，所有只读数据位置连续，所有可读可写数据位置连续，这些连续区域由 ____ 表描述。
答案：程序头（段头）
32.填空运行时用户栈从用户空间的最大地址往 ____ 地址方向增长。
答案：低
33.填空ELF 头的 e_entry 字段给出程序的 ____ 地址，可重定位文件中此字段为 0。
答案：入口（执行入口）
34.填空i386 System V ABI 规定可读/写数据段映射到只读代码段后面按 ____ 对齐的高地址上。
答案：4KB
35.填空堆区和栈区中间保留一块空间给 ____ 的目标代码。
答案：共享库
36.名词解释节（Section）
ELF 文件中的主体信息单元，包含了链接过程所用的目标代码信息，包括指令、数据、符号表和重定位信息等。
37.名词解释程序头表（Program Header Table）
也称段头表，是可执行文件中的一个结构数组，描述可执行文件中各「段（Segment）」到进程虚拟地址空间的映射关系，由操作系统加载器使用。
38.名词解释魔数（Magic Number）
文件开头几个字节的固定特征值，用来在加载/读取时确认文件的类型或格式是否正确，例如 ELF 文件以 0x7F 'E' 'L' 'F' 开头。
39.综合题请按地址从低到高的顺序，列出 IA-32+Linux 进程的虚拟地址空间中常见区域。
答案：
从低到高大致为：
① 保留区（低地址 0 附近不可用）
② 只读代码段（.text + .rodata，起始 0x08048000）
③ 可读/写数据段（.data + .bss，按 4KB 对齐）
④ 运行时堆（run-time heap，malloc 向高地址扩展）
⑤ 共享库映射区
⑥ 用户栈（user stack，从最大地址向低地址增长）
⑦ 内核虚拟存储区（最高地址区）

第三节 符号解析与重定位

24 题
40.单选以下哪类「不是」符号表中需要包含的符号？
  • A. 非静态函数名
  • B. 全局变量名
  • C. 带 static 属性的本地变量名
  • D. auto 型非静态局部变量名
答案：D
auto 局部变量在栈中管理，链接器不需要其信息，故不进入 .symtab。
41.单选符号表中由其他模块定义、被本模块引用的全局符号称为？
  • A. 全局符号
  • B. 外部符号
  • C. 本地符号
  • D. 弱符号
答案：B
Global / External / Local 三类：①本模块定义并被其他模块引用=Global；②其他模块定义并被本模块引用=External；③本模块内定义并引用=Local（含 static 变量）。
42.单选符号解析中，多个同名 COMMON 符号同时定义时，链接器选择？
  • A. 任意一个
  • B. 最小长度的一个
  • C. 占用空间最大的一个
  • D. 抛出链接错误
答案：C
COMMON 块规则：链接器取「最小长度中的最大值」，以满足所有同名 COMMON 符号的空间要求。
43.单选对于模块内部的 static 本地变量，链接器如何处理？
  • A. 编译器为它们在 .data 或 .bss 中分配空间，并作为不同符号记录到符号表
  • B. 分配在栈中并放入符号表
  • C. 不分配空间，链接时再决定
  • D. 编译时直接丢弃
答案：A
static 本地变量不在栈中，由编译器在 .data/.bss 中分配，并在 .symtab 中以独立符号记录。
44.单选类 UNIX 系统中静态库文件的后缀和格式是？
  • A. .so / ELF
  • B. .a / 存档档案（Archive）
  • C. .lib / COFF
  • D. .dll / PE
答案：B
静态库 .a，使用 Archive 格式（ar 工具创建）。.so 是共享库。
45.单选重定位过程需要借助哪个节中的「重定位表项」完成？
  • A. .symtab
  • B. .text
  • C. .data
  • D. .rel.text 和 .rel.data
答案：D
.rel.text/.rel.data 记录需要重定位的符号引用位置和所引用的符号。
46.单选下列关于「共享库」描述错误的是？
  • A. 共享库代码段在内存中每个进程各有一份副本
  • B. 共享库具备「共享性」与「动态性」
  • C. 共享库由动态链接器完成链接
  • D. 共享库更新后无需重新链接应用程序
答案：A
共享库的代码段在内存中只有「一份副本」，被所有进程共享，正是「共享性」的体现。
47.单选共享库的「动态性」体现在？
  • A. 编译时静态绑定
  • B. 链接时确定所有地址
  • C. 共享库只在程序加载或运行时才装入内存
  • D. 共享库不能被卸载
答案：C
动态性：共享库在被使用时才装入，更新后应用程序无需重新链接。
48.单选动态链接的两种方式是？
  • A. 加载时链接 + 运行时链接
  • B. 静态链接 + 动态链接
  • C. 编译时链接 + 加载时链接
  • D. 显示链接 + 隐式链接
答案：A
①加载时动态链接（程序装入时完成）；②运行时动态链接（程序运行中按需装入，如 dlopen）。
49.单选关于弱符号（weak symbol）的描述，正确的是？
  • A. 优先级高于强符号
  • B. 可被同名强符号覆盖
  • C. 多个弱符号同名时链接器报错
  • D. 不能出现在全局变量中
答案：B
规则：强符号只能有一个；多个弱符号同名时按「最大长度」处理；强+弱同名时，强覆盖弱。
50.单选下列选项中，「不属于」强符号（strong symbol）的是？
  • A. 已初始化的全局变量
  • B. 函数名
  • C. 定义时未使用 static 关键字的全局变量
  • D. 未初始化的全局变量（C 语言习惯）
答案：D
C 习惯：未初始化全局变量按「弱符号 / COMMON」处理；已初始化或带 static 的全局变量是强符号。
51.填空符号表中共三类符号：本模块定义被其他模块引用的「全局符号」、其他模块定义被本模块引用的 ____ 符号、本模块内定义并引用的「本地符号」。
答案：外部
52.填空重定位分为「节和定义符号的重定位」与「____ 的重定位」两个方面工作。
答案：引用处符号
53.填空类 UNIX 系统的静态库使用 ____ 后缀的特殊存档文件格式。
答案：.a
54.填空动态链接器也称为 Dynamic ____，负责装入并链接共享库。
答案：Linker
55.填空共享库的两大特点是「共享性」与 ____。
答案：动态性
56.填空链接器对 .text 中所有符号引用进行重定位时依据的是 ____ 节中的重定位表项。
答案：.rel.text
57.填空链接器通常用 ____ 命令将 .a 中被实际引用到的目标模块提取出来与应用程序链接。
答案：ld（链接器）
58.名词解释全局符号（Global Symbol）
在模块 m 中定义并被其他模块引用的符号，包括非静态的函数名和全局变量名，可被其他模块访问。
59.名词解释本地符号（Local Symbol）
在模块 m 中定义且仅在 m 内引用的符号，主要指带 static 属性的函数名和全局变量名，由编译器在 .data/.bss 中分配空间并记录到符号表。
60.名词解释静态库（Static Library）
由链接器在构建可执行文件时使用的库文件机制，将一组可重定位目标模块打包成一个 .a 后缀的存档档案，链接器自动从库中抽取被引用到的模块并与应用模块链接。
61.名词解释共享库（Shared Library）
一种特殊的可重定位目标文件（.so），可在可执行文件装入或运行时被动态地装入内存并自动链接，由动态链接器完成，具备共享性（内存中代码段仅一份）和动态性（按需装入、无需重链应用）。
62.名词解释动态链接（Dynamic Linking）
在程序加载时或运行过程中，把共享库装入内存并完成符号解析与重定位的链接方式，由动态链接器完成，分为加载时链接和运行时链接两种。
63.综合题为什么 auto 型非静态局部变量不在符号表中？链接器不需要它们会引起什么后果？
答案：
auto 局部变量随函数调用在栈帧中动态分配、随函数返回而释放，其生命周期只属于本次调用，链接器在合并模块时不需要也无法跨模块访问它们，因此不进入 .symtab。
后果：不同模块可以各自定义同名 auto 变量而互不干扰；但同时也意味着链接器无法为它们分配固定地址、不能跨函数保留值（C++ 中 static 局部变量则进入符号表，由编译器在 .data/.bss 中分配全局唯一的存储）。

第四节 可执行文件的加载

20 题
64.单选下列关于「程序」与「进程」描述正确的是？
  • A. 进程是静态的代码集合
  • B. 一个程序可以被加载多次，对应多个进程
  • C. 程序具有动态性
  • D. 进程可以脱离程序存在
答案：B
程序=静态的代码+数据集合；进程=程序在某数据集合上的一次运行活动，动态性。一个程序可对应多个进程。
65.单选进程的虚拟地址空间信息保存在哪？

67.单选main 函数的 argv 参数中，argv[0] 通常指向？

68.单选关于 fork 函数返回值的描述，正确的是？
  • A. 子进程中返回子进程 PID，父进程中返回 0

  • C. 父子进程都返回相同 PID

69.单选fork 创建的子进程与父进程相比，下列哪项「不同」？

71.单选关于 fork 后父子进程之间的关系，错误的是？
  • A. 父子进程都从 fork 返回处继续执行
  • B. 子进程获得父进程的文件描述符副本
  • C. 修改任一方虚拟地址空间不会影响另一方
  • D. 父子进程共享同一份物理内存
答案：D
fork 后父子进程拥有相同但独立的虚拟地址空间；写时复制（COW）机制下初时共享物理页，一旦任一方写入则复制新页。

答案：int
78.名词解释程序（Program）
代码和数据的集合，程序的代码是一个机器指令序列，作为文件存放在硬盘中，是静态的概念。
79.名词解释进程（Process）
具有一定独立功能的程序关于某个数据集合的一次运行活动，具有动态的含义；一个可执行文件可被加载多次，对应多个不同的进程。
80.名词解释execve 函数
在当前进程的上下文中加载并运行一个新程序的系统调用，原型为 int execve(char *filename, char *argv[], char *envp[])，成功调用后进程的代码、数据全部被新程序替换。
81.名词解释fork 函数
Linux 中用于创建子进程的系统调用，原型为 pid_t fork(void)；子进程获得与父进程相同但独立的虚拟地址空间与文件描述符表，两者从 fork 返回处继续执行，区别在于返回值（子进程 0，父进程返回子进程 PID）。
82.综合题简述在 Linux 中通过 fork+execve 启动一个新程序的典型流程。
答案：
① 父进程调用 fork()，复制出一份与父进程几乎一样的子进程；
② 父进程通常根据 fork 返回值 >0 继续执行或调用 wait() 等待子进程；
③ 子进程判断 fork 返回值 =0 后调用 execve(filename, argv, envp)；
④ execve 加载 filename 指定的 ELF 可执行文件，根据其程序头表建立新的虚拟地址空间映像（替换原地址空间），并从 e_entry 入口开始执行；
⑤ 子进程执行完后通过 exit() 返回，父进程在 wait() 中被唤醒并回收子进程资源。
该模式让父子进程各司其职：父进程可继续服务或并发派生子进程，子进程独立加载并运行目标程序。
83.综合题fork 后父子进程共享哪些资源？又各自独立哪些资源？
答案：
共享（继承的）：打开的文件描述符表、信号处理方式、当前工作目录、用户 ID/组 ID 等进程属性。
独立：进程 PID、虚拟地址空间（fork 时复制，写时复制）、父进程 PID、未决信号集等。
关键点：fork 后两者拥有相同但独立的虚拟地址空间，任一方写入会触发 COW 复制，互不影响。

86.单选CPU 执行一条指令大致分为 6 步，下列顺序正确的是？
  • A. 取指 → 译码 → 算源地址 → 算目的地址并存结果 → 执行数据操作 → 算下条指令地址
  • B. 取指 → 译码 → 算源地址并取操作数 → 执行数据操作 → 算目的地址并存结果 → 算下条指令地址
  • C. 译码 → 取指 → 算源地址 → 存结果 → 执行 → 算下条地址

答案：B
六步：取指 → 译码 → 计算源操作数地址并取操作数 → 执行数据操作 → 计算目的操作数地址并存结果 → 计算下条指令地址。
87.单选CPU 中「操作控制信号形成部件」综合的三类信息不包括？

88.单选CPU 中「启停控制逻辑」的作用是？

启停控制逻辑：在需要时开放/封锁时钟信号，实现启动与停机。
89.单选内部异常（Exception）与外部中断（Interrupt）的本质区别在于？
  • A. 异常由软件产生，中断由硬件产生
  • B. 中断可屏蔽，异常不可屏蔽
  • C. 异常由 CPU 执行某条指令时自身引起，与指令相关；中断由 CPU 外部的 I/O 子系统发出，与执行的指令无关
  • D. 异常优先级一定比中断高
答案：C
关键区分：异常由指令自身触发（除 0、溢出、断点等）；中断由外部 I/O 事件触发（时钟、网络包、Ctrl+C 等）。
90.单选CPU 对异常和中断的响应过程通常分为三步，下列顺序正确的是？

  • B. 保护断点和程序状态 → 关中断 → 识别异常和中断事件并转相应处理程序
  • C. 关中断 → 识别事件 → 保护断点
  • D. 保护现场 → 开中断 → 识别事件
答案：B
标准三步：保护断点和程序状态 → 关中断 → 识别事件并转入对应处理程序。
91.单选「关中断」通常由 CPU 通过什么机制实现？

  • B. 修改 PC
  • C. 屏蔽数据线
  • D. 关掉时钟
答案：A
IF 中断使能位 = 1 开中断，= 0 关中断（响应过程中由 CPU 自动清 0）。
92.单选关于「向量中断」方式的描述，正确的是？
  • A. 由软件逐个查询中断源
  • B. 需要 CPU 主动轮询
  • C. 比软件识别速度慢
  • D. 每种异常/中断都有中断类型号，根据类型号在中断向量表中找到对应处理程序首地址
答案：D
向量中断=硬件识别：每种异常/中断对应一个中断类型号，通过中断向量表直接跳转到处理程序入口。
93.单选指令流水线设计中，流水段数 M 与每段执行时间 T 的关系，下列正确的是？

  • B. 段数与时钟频率无关
  • C. 流水段数以最复杂指令的阶段数为准，每段执行时间以最复杂操作所用时间为准

流水线设计原则：段数以最复杂指令所用阶段数为基准；段执行时间以最复杂操作为基准（同步各段）。
94.单选理想情况下，N 条指令在 M 段流水线中执行的总时间为？

96.单选CPU 检测到中断请求后，所保存的「断点」一般是？

每条指令执行完后 CPU 才检查中断请求，因此断点 = 下一条指令地址。

108.名词解释内部异常（Exception）
由 CPU 在执行某条指令时引起的与该指令相关的意外事件，如除数为 0、结果溢出、断点、单步跟踪、缺页、地址越界、非法操作码等，与执行的指令相关。
109.名词解释外部中断（Interrupt）
由 CPU 外部的 I/O 子系统发出的事件，如时钟中断、网络数据包到达、用户按键等，通过外部中断请求线向 CPU 发请求；与当前执行的指令无关。
110.名词解释向量中断
硬件识别异常/中断的方式：每种类型对应一个中断类型号，所有异常/中断处理程序首地址组成中断向量表，CPU 根据类型号直接索引到对应处理程序入口，速度快。
111.名词解释指令流水线
把一条指令的执行过程划分为多个流水段，多条指令的不同段在时间上重叠执行的并行处理技术；理想情况下 N 条指令在 M 段流水线上总时间为 (M-1+N)×T，显著提升吞吐率。
112.名词解释指令寄存器（IR）
CPU 内部用于暂存当前正在译码/执行的指令的寄存器；指令从存储器取出后必须先送入 IR，才能送往指令译码器译码。
113.综合题CPU 执行一条指令的 6 步骤是什么？每步的核心操作是什么？
答案：
① 取指令：根据 PC 内容访存，将指令取出送入 IR。
② 指令译码：对 IR 中操作码部分译码，产生操作控制信号基础。
③ 计算源操作数地址并取操作数：按寻址方式计算源地址，必要时访存取操作数。
④ 执行数据操作：在 ALU / 加法器中对操作数执行运算。
⑤ 计算目的操作数地址并存结果：按寻址方式得到目的地址，将结果写入寄存器或存储器。
⑥ 计算下条指令地址并送 PC：顺序时 PC+指令长度；跳转时将目标地址送 PC。
114.综合题假设一段程序含 100 条指令，流水线段数 M=4，每段时间 T=10ns，求理想情况下该段程序的总执行时间和吞吐率（条/ns）。
答案：
总时间 T_total = (M - 1 + N) × T = (4 - 1 + 100) × 10 = 1030 ns。
吞吐率 TP = N / T_total = 100 / 1030 ≈ 0.097 条/ns ≈ 1/(M·T) 当 N≫M 时极限吞吐率 = 1/T = 0.1 条/ns。
